# Решения задач с Codewars на C#

[![Codewars](https://img.shields.io/badge/Codewars-Профиль-red?style=for-the-badge&logo=codewars)](https://www.codewars.com/users/friestr)

> Моя личная коллекция решений задач с [Codewars](https://www.codewars.com/) на языке **C#**.  
> Репозиторий служит личным архивом и способом отслеживать прогресс в изучении алгоритмов, структур данных и чистого кода.

---

## 📂 Структура

Решения организованы по **уровням сложности (kyu)**. Чем ниже kyu — тем сложнее задача.

```
.
├── 8Kyu/          # Для начинающих — основы синтаксиса, простая логика
├── 7Kyu/          # Лёгкие — массивы, строки, базовый LINQ
├── 6Kyu/          # Средние — алгоритмы, коллекции
├── 5Kyu/          # Продвинутые — рекурсия, оптимизация, математика
├── 4Kyu/          # Сложные — комплексные алгоритмы, динамическое программирование
├── 3Kyu/          # Экспертные — глубокие алгоритмические задачи
├── 2Kyu/
└── 1Kyu/          # Мастерские — самые сложные задачи платформы
```

В каждой папке лежат `.cs` файлы, названные по имени задачи.  
В каждом файле есть:
- 🔗 Ссылка на оригинальную задачу на Codewars
- ✅ Класс с методом `Solution`
